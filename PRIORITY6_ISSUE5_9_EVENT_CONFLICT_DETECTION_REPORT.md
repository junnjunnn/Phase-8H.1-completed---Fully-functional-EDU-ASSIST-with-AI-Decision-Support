## 3. Conflict detection design

`BACKEND/attendance/conflicts.py` evaluates candidate events against dated `SchoolCalendarDay` records in the same academic year. Date ranges are respected, cancelled and archived entries are ignored, and the candidate is excluded during updates.

Recurring definitions are checked against already-generated dated occurrences using the existing recurrence date generator. No new occurrences are generated by conflict checking.

## 4. Conflict classifications

- `TIME_OVERLAP`: overlapping start/end times; warning by itself.
- `LOCATION_CONFLICT`: same location with overlapping times; actionable error.
- `SECTION_CONFLICT`: same section with overlapping times; actionable error.
- `SCOPE_CONFLICT`: overlapping school-wide, grade, department, or time-specific scope with overlapping times; actionable error.

Same-date events without overlapping times, location, or scope are not classified as conflicts.
